# Synthetic threshold calibration

Generated by `scripts/calibrate_thresholds.py`. This measures routing decisions, not OCR transcription accuracy.

Candidate settings evaluated: **144**. Selection uses development labels only, prioritizing missed OCR pages, incorrect full-page escalation, unnecessary OCR, then distance from defaults.

Whole scenario families are separated between development and held-out sets. Synthetic labels are explicit expectations, not statistical calibration on real documents.

## Recommended settings

```json
{
  "near_empty_characters": 5,
  "garbage_share_threshold": 0.01,
  "image_coverage_threshold": 0.8,
  "min_words_per_area": 2e-05
}
```

The defaults are retained when candidates tie; these examples provide no evidence to change them.

## Limits and excluded cases

- Decorative-logo fixtures are excluded from threshold selection: repetition-based decoration detection belongs to layout, and raw readers have not marked those images decorative.
- Word embedded-image routing is now included in held-out labels: the reader exposes an actual raster asset and a synthetic region. Transcription assertions are recorded by the separate full-pipeline evaluation.
- Invalid upload fixtures are validated separately and never enter this routing loop.
- Coverage, density and near-empty thresholds cannot be independently calibrated by this corpus: any nondecorative image already triggers region OCR. Defaults remain provisional.
- No real-world accuracy percentage is claimed. Fonts, handwriting, low contrast, damaged pages and unusual layouts need independently labelled real documents.
